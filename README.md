# VIVA Jugos y Café

App de pedidos para recoger (web/PWA y Android) con **Panel del negocio** para
que el dueño administre menú, precios, fotos, horarios y pedidos.

- Puesta en marcha y permisos: [docs/PANEL-NEGOCIO.md](docs/PANEL-NEGOCIO.md)
- Publicar la app web: [docs/APP-WEB.md](docs/APP-WEB.md)

Basada en el código de juicebar (Expo + Supabase). Este negocio no usa Clover:
el catálogo es propio y se paga en el mostrador.
